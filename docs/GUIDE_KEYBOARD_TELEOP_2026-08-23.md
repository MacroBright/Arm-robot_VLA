## 一、这是什么

**PC 直连 CAN 的键盘遥操工具** —— 用键盘控制机械臂末端在笛卡尔空间（基座系 x/y/z）平滑移动，用于**按摩动作示教 / 轨迹采集**（P4 数据采集预备）。

- **控制方式**：末端**速度控制**（mm/s），雅可比数值 IK 局部映射 → 每帧小步进，任意姿态可用、不翻腕
- **闭环**：每帧读 0x36 真实角 → FK 反馈 → 看门狗
- **姿态**：遥操中锁当前工具朝向（ω=0），只动位置

### 与 zdt_interactive.py 的分工

| | cartesian_keyboard.py | zdt_interactive.py |
|---|---|---|
| 定位 | **末端笛卡尔遥操**（高级） | 底层调试/标定（低级） |
| 控制量 | 末端速度 (mm/s) | 关节角/脉冲 |
| 安全 | 雅可比 + 限位守卫 + 看门狗 + 急停 | 无软限位，全靠手动 |
| 用途 | 按摩示教、轨迹采集 | 标定、排障、生产驱动测试 |

> 首次使用前先看 **[ACCEPTANCE_KEYBOARD_TELEOP](ACCEPTANCE_KEYBOARD_TELEOP_2026-08-21.md)** 的验收流程，真机验证过坐标帧与方向后再做示教。

## 三、启动

```bash
cd Arm-robot_VLA
./scripts/bringup/can_setup.sh                          # can0 @ 500k

# 方式 A: conda 环境已激活
python scripts/control/cartesian_keyboard.py

# 方式 B: 显式指定解释器
~/win_office/conda/envs/smolvla/bin/python scripts/control/cartesian_keyboard.py
```

可选参数：
```
--iface can0      # SocketCAN 接口 (默认 can0)
```

**启动流程（窗口先开 → 打印状态 → 按 R 回 ready）**：

1. 连接并打开遥操窗口（**不自动回 ready**）
2. 窗口打开后打印 **6 轴真实状态表**（anchor° / ready目标° / 电流mA / 标志），供确认机械臂状态（坐标帧/寄存器对齐）
3. **按 `R`** 才回 ready（安全速度 100 RPM 同步）；按 `H` 回上电姿态全 0；姿态运动期间窗口显示进度

示例输出：
```
[键盘遥操] 当前 6 轴状态 (0x36 真实角):
  J#   anchor°   ready目标  电流mA  标志
  J1    -0.00     +0.0     100  0x83[使能,到位]
  J2    -0.04    +60.0     100  0x83[使能,到位]
  ...
  目标: R=ready [0,60,50,0,120,0] / H=回上电姿态全 0 / SPACE=急停
```

## 四、按键映射

| 按键 | 作用 | 说明 |
|------|------|------|
| `W` / `S` | 末端 **+x / -x** | 基座系，前后 |
| `A` / `D` | 末端 **+y / -y** | 左右 |
| `Q` / `E` | 末端 **+z / -z** | 上下 |
| `Shift` | **循环切换档位** | 慢 20 → 中 40 → 快 60 mm/s → 慢；窗口速度行按档位配色（慢白/中浅蓝/快橙）显示 |
| `R` | 回 **ready** 姿态 | 任意位置回 [0,60,50,0,120,0]，安全速度同步 |
| `H` | 回**上电初始姿态** | 任意位置回全 0 [0,0,0,0,0,0]，安全速度同步 |
| `SPACE` | **急停** (e_stop) | 立即停，保持力矩 |
| `ESC` / `Ctrl+C` | 退出 | 先急停再断开 |

速度：慢 20 / 中 40 / 快 60 mm/s（单轴）。可组合键（如 W+A 斜向）。R/H 姿态运动期间运动键被忽略（仅 SPACE/ESC 有效）。

## 五、窗口显示说明

960×420 窗口，四档字号：

| 行 | 内容 | 说明 |
|----|------|------|
| 标题 | 运行中 / 急停 / 姿态运动中 | 绿=正常，红=急停，黄=回 ready/上电中 |
| 速度 | `(vx, vy, vz) mm/s` + 档位（慢白/中浅蓝/快橙） | 当前下发速度与档位 |
| 末端 | `(x, y, z) mm` | **FK 反馈**（读真实角，非命令积分） |
| 状态/按键 | 实时按键 / 瞬态提示 | 未运动/急停等提示约 2 秒 |
| 提示 | 按键说明 + 档位/聚焦提醒 | — |

**末端数值是安全参考**：应随按键平滑单调变化；若跳动/反向，立即松手。

## 六、操作教程（分步）

### 1. 启动与就位
启动脚本 → 窗口弹出 → 打印 6 轴状态表 → **按 `R` 回 ready**（安全速度同步，窗口显示进度）→ 到位后确认末端 ≈ **ready FK 值 (0, -188, -90)** → 静置看数值稳定（<0.5mm 抖动）。

### 2. 单轴方向验证（第一次使用必做）
每个键**轻点一下**看方向，确认对了再按住：
```
W → x 增大   S → x 减小
A → y 增大   D → y 减小
Q → z 增大   E → z 减小
```
**方向反了或松手不停 → 立即 SPACE 急停**，查坐标帧（不能继续）。

### 3. 慢速遥操（20 mm/s）
- 按住单键或组合键，末端沿指定方向平滑移动
- **松手即停**（无惯性滑行）
- 观察末端数值连续变化、无顿挫

### 4. 档位切换（Shift 循环）
**按一下 `Shift`** 在慢档(20)→中档(40)→快档(60) 间循环，窗口速度行配色（慢白/中浅蓝/快橙）实时显示当前档位。慢档用于示教精度，中档一般操作，快档仅长距离搬运。⚠ 档位是**锁存状态**——不遥操时切回慢档，避免误触方向键高速运动；快档更早松手留刹车距离。

### 5. 回 ready（R）与回上电（H）
- **`R`**：任意位置回 ready [0,60,50,0,120,0]，安全速度同步。适合示教手法后复位
- **`H`**：任意位置回上电初始姿态全 0 [0,0,0,0,0,0]，安全速度同步。适合收工/重新开始
- 姿态运动期间窗口显示 `[回ready/回上电 运动中] + 最大偏差 X°`，运动键被忽略；到位后自动恢复遥操

### 6. 急停与退出
- **SPACE**：急停（断命令保力矩，臂不掉）；标题变红"急停"
- **ESC / Ctrl+C**：退出（先急停再断开）
- 再次使能：重启脚本（自动使能；回 ready 需按 `R`）

### 7. 按摩示教建议（P4 预备）
- **每个 episode 从 ready 姿态开始**（按 `R` 或重启脚本）
- 末端速度保持平滑（避免快速反向），利于后期轨迹学习
- 手法（按/揉/推）用慢档，转折处提前减速

## 七、安全注意事项

1. **物理急停优先**：SPACE 是软件急停，真机危急用物理按钮
2. **保持窗口聚焦**：窗口失焦时按键可能卡住（KEYUP 丢失），机械臂持续运动——松手前先确认聚焦
3. **J2/J3 重力关节**：全程使能保力矩；急停只断命令不断电，臂不会掉
4. **限位**：持续压向一个方向 → 触及 J2/J3/J4/J5 限位 → 单轴停 + 终端 `limit_alarm`，属正常保护
5. **首次使用先方向验证**：坐标系错误时按键方向会反，务必先轻点确认

## 八、故障排查

| 现象 | 原因 | 处理 |
|------|------|------|
| `ik_no_solution` 刷屏 | **旧版代码**（解析 IK 已废弃） | 更新代码，雅可比版本不再出现 |
| `step 异常: TimeoutError ... func=36` | CAN 读取超时：总线电气/驱动器不响应/电源问题 | 检查接线、终端电阻、电源；脚本会急停退出 |
| **anchor 全变 0（寄存器清零）** | 驱动器掉电重启（0x36 是 RAM） | **停止遥操**，断电排查；恢复后回开机姿态重新对齐 |
| 某轴缺"到位"位 (0x81) | 该轴未参与 ready 运动，正常 | 观察，无堵转标志即可继续 |
| `limit_alarm` 停车 | 目标关节角越出限位 | 属正常保护；反向移动回安全区 |
| 窗口中文乱码 | 系统缺中文字体 | 已内置 CJK 字体回退链，确认字体存在 |
| 按键"卡住"持续运动 | 窗口失焦 KEYUP 丢失 | 保持聚焦；SPACE 急停兜底 |
| 快档太快 | 60 mm/s 响应距离长 | 用慢档示教，快档仅长距离搬运 |

### 寄存器清零恢复流程（重要）

若 `all status` 显示 6 轴 anchor 全 ≈0 但机械臂**不在开机姿态**：
1. **立即停止运动**（模型与实物已失步，命令不可信）
2. 排查驱动器供电（PSU 容量、接线、是否有掉电重启）
3. 把机械臂**物理退回开机姿态**（手臂竖直，各关节≈0），手扶 J2/J3
4. 确认 `scan` 电机轴 ≈0 → 在交互工具 `prod ready` 重新回 ready
5. `all status` 复核 anchor ≈ [0,60,50,0,120,0] 后恢复遥操
