# ZDT 电机驱动端设置与关节校准操作指南

> 2026-08-14 | 真机电机驱动端 bring-up
> 适用：STM32(已适配 ZDT 固件) ↔ CAN 总线 ↔ ZDT X系列 V2 步进闭环驱动器 ×6
> 依据：`ZDT_X系列_V2步进闭环驱动说明书Rev1.0.md`（§三/§五/§七/§八/§12）

---

## 0. 链路与前置确认

| 项 | 值/说明 |
|----|---------|
| 物理链路 | STM32 CAN1 ↔ 6×ZDT 驱动器 CAN（扩展帧），24V 供电 |
| PC↔STM32 | 串口 115200 行文本协议（`get_state/set_joints/remote_event/rel_rotate/e_stop`） |
| 驱动端操作 | 每个驱动器小屏幕 OLED 菜单 + 按键（Enter 进入/确认） |
| 前提 | `rel_rotate` 已走通 → 驱动通信参数（ID/波特率/校验）已能与固件匹配；本文聚焦**编码器校准、关节零点、限位、安全参数** |

> ⚠ **安全准则**：任何校准/回零操作在**空载或低负载**、**无人在手臂活动范围内**进行；先发 `e_stop` 确认急停可用；按摩相关测试先用假体。

## 1. 首次上电编码器校准（每轴一次，空载）

**必须在闭环控制前完成**。若上电后屏幕提示 `Not Cal`，说明从未校准。

**操作**（说明书 §三）：
1. 给单个驱动器 12-32V 供电（推荐 24V），其他引脚可先不接；
2. 屏幕出现 `Not Cal` 后按 Enter 确认 **Cal**；
3. 电机"哔"一声后**正转一圈 → 反转一圈 → 高速运行几秒**（高速段仅首次校准执行）；
4. 运行结束即完成，可正常控制。

**异常处理**：

| 提示 | 含义 | 处理 |
|------|------|------|
| `Phase A+ A- Error!` / `Phase B+ B- Error!` / `Phase AA BB Error!` | 电机线序错误 | A+A-/B+B- 分两组（57 步进一般黑绿一组、红蓝一组；万用表蜂鸣档测导通的两根为同组） |
| `Waiting V+ Power` | 供电电压太低 | 提供 12-32V，推荐 24V |
| `Magnet Loss! Enter..` | 编码器没检测到磁铁 | 按 §2.2 装磁铁/固定驱动板到电机背后 |
| `Ref Voltage Error!` | 基准电压芯片故障 | 联系客服 |

> 校准务必**空载**（不连减速器负载/不带动臂重物），否则线性化不准。换电机/换驱动板需重新校准。

## 2. 通信参数确认（已对齐，读回核验）

`rel_rotate` 已走通 → 以下参数**已匹配固件**，仅需逐轴读回核验（避免个别轴装错）：

| 菜单 | 应为 | 说明 |
|------|------|------|
| `P_Serial` | `CAN1_MAP` | 通讯端口复用为 CAN |
| `CAN_Baud` | 与固件一致（默认 `500000`） | 若固件用 1M 则设 `1000000`，**6 轴必须一致** |
| `ID_Addr` | **每轴唯一，按 CAN 2-7 分配**（已确认） | 关节 i → 地址 i+1：J1=2, J2=3, J3=4, J4=5, J5=6, J6=7，与固件 `joint_id+1` 寻址一致（原 Emm_V5 遗留约定） |
| `Checksum` | `0x6B`（默认） | 若固件用 XOR/CRC-8 则对应切换 |
| `Response` | `None`（遥操推荐）或 `Receive` | `None` 减总线流量，50Hz 遥操更稳 |
| `S_PosTDP` | 与固件换算一致（默认 `Disable`） | **若 Enable，所有位置命令/返回 ×100（0.01°）**，固件换算必须一致，否则错位 100 倍 |
| `CtrlMode` | `CR_VFOC`（闭环） | 开环无法闭环力控/堵转保护 |
| `En` | `Hold`（默认，不接线一直使能） | 调试安全时改 `L` 可断电手拧 |

**读回核验**：
- OLED 菜单逐项查看；
- 或发 CAN 命令 `01 42 6C 6B`（读驱动参数，返回 37 字节按 §12.3 解析）；
- 或发 `01 36 6B`（读实时位置）确认能收到回帧。

## 3. 控制与安全参数

| 菜单 | 建议 | 说明 |
|------|------|------|
| `Ma_Limit` | 按负载实测，如 2000-3000mA | 闭环最大相电流；按摩力控上限在这设保守值 |
| `Vm_Limit` | 先 300-600 RPM（降低冲击） | 最大转速，遥操跟手后再调高 |
| `Clog_Pro` | `Enable` | **堵转保护（按摩碰撞安全关键）**：堵转时自动关闭驱动器，蓝色 LED 提示 |
| `Clog_Rpm` | 8（默认） | 堵转检测转速阈值 |
| `Clog_Ma` | 按实测标定（默认 2000） | 堵转检测相电流阈值：**让电机带负载正常运动，记当前电流，取略大值** |
| `Clog_Ms` | 2000（默认 ms） | 堵转检测持续时间阈值 |
| `Dir` | 每轴按装配方向设 CW/CCW | 保证 6 轴正方向一致（配合固件 `MOTOR_DIR_*`） |
| `O_POT_En` | 见 §4 | 上电自动回零开关 |

> 触发堵转条件：转速<`Clog_Rpm` 且 相电流>`Clog_Ma` 且 持续>`Clog_Ms`。若设得过严，正常慢速受力会被误判堵转，需实测回调。

## 4. 关节零点校准（关节校准）

> 目标：每轴机械零位 = 驱动器角度 0°，与固件 `g_joints_init` 的初始位对齐。

### 方案 A：单圈就近回零（推荐，机械臂关节多为单圈）

1. 把关节**手动/缓慢运动到期望零位**（装配零点，通常取行程中点或与固件初始位一致）；
2. 菜单 `O_Set` → `Set O`；或发 `01 93 88 01 6B`（设单圈零点，存储标志 01）；
3. `O_Mode` = `Nearest`（单圈就近回零）；
4. 触发回零：发 `01 9A 00 00 6B`，或（可选）`O_POT_En` = `Enable` 实现**上电自动回零**（每次上电自动回到该零位，保证可重复）；
5. 回零方向/速度：`O_Dir`（CW/CCW）、`O_Vel`（30-300 RPM）、超时 `O_Tmo_Ms`。

### 方案 B：多圈无限位碰撞回零（机械臂无额外限位开关时用）

原理：电机顶到机械结构边缘 → 电流瞬间变大、转速变小 → 判定到原点。前提：负载固定。

1. 用直通限速位置模式带负载正常运动，记小屏幕相电流（如 ~637mA）；
2. `O_Mode` = `Senseless`；`O_SL_Ma` 设略大于实测（如 800mA）；`O_SL_Rpm` = 300；`O_SL_Ms` = 60；
3. 回零方向 `O_Dir` 不对则翻转；
4. 触发：发 `01 9A 00 00 6B` 或 `O_POT_En`=`Enable` 上电自动。

### 方案 C：多圈有限位开关回零

需要限位开关接 En/Dir 复用引脚（`P_Pul` = `ESI_RCO` 或 `P_Serial` = `ESI_ALO`），仅当硬件装有限位开关时用。

> 固件 `soft_reset` 目标位（当前 [90,45,90,90,0,0]）应与 §4 的零点定义一致，保证「复位→回零→读数一致」。

## 5. 关节限位

> ⚠ **关键**：**ZDT 驱动器本身没有软限位**（无位置上限/下限寄存器）。关节限位必须在上层实现，驱动器只能提供堵转保护兜底。

### 5.1 STM32 固件层（主限位）
固件已有框架（`robot.c`）：
- `g_joints_init[]` 每轴 min/max 角度 clamp（位置命令越界拒绝/钳制）；
- 限位开关 GPIO（`ROBOT_STATUS_LIMIT_*`）可选接入；
- `remote_event` 速度模式下对 J5/J6 目标角 clamp（真机视觉遥操已依赖此逻辑）。

当前文档标注范围（真机实测为准，见下）：

| 关节 | 范围（°） | 备注 |
|------|:--------:|------|
| J1 shoulder_pan | 0 ~ 360 | 底座旋转 |
| J2 shoulder_lift | 90 ~ 180 | 肩部抬升 |
| J3 elbow_flex | -90 ~ 90 | 肘部 |
| J4 wrist_roll | -90 ~ 90 | 末端旋转（真机实测） |
| J5 wrist_flex | 0 ~ 90 | 末端上下（真机实测） |
| J6 gripper | 0 ~ 360 | 末端旋转（真机实测） |

### 5.2 真机实测标定（建议做）
逐轴用 `rel_rotate joint_id ±step` 小步进慢扫，记录**机械极限角度**，与文档值比对、修正后写回固件 clamp：
```
rel_rotate 1 +5    # 关节1 正转 5°，重复直到抵死
get_state           # 记录实际极限角
rel_rotate 1 -5    # 反转，重复，记录负极限
```

### 5.3 驱动端兜底（堵转保护）
`Clog_Pro`=`Enable`（§3）。撞到机械限位/人手/异物 → 相电流骤升 → 驱动自动停机。**这是按摩场景最后一道保护，务必开**。

## 附录 A：关键 ZDT 命令帧（0x6B 校验，CAN 扩展帧 ID=(Addr<<8)）

| 功能 | 帧（16进制） | 说明 |
|------|--------------|------|
| 使能 | `01 F3 AB 01 00 6B` | 01=使能 / 00=不使能 |
| 立即停止 | `01 FE 98 00 6B` | 广播 `00 FE 98 00 6B` 全停 |
| 直通限速位置 | `01 FB 00 速度2B 位置3B 0A 同步1B 6B` | 位置×10；绝对=01/相对=00；速度 RPM×10 |
| 速度模式 | `01 F6 00 斜率2B 速度2B 同步1B 6B` | 转速 RPM×10 |
| 读实时位置 | `01 36 6B` | 返回 地址36 符号 位置(×10) 6B |
| 读相电流 | `01 27 6B` | 返回 mA |
| 设单圈零点 | `01 93 88 01 6B` | 01=存储 |
| 触发回零 | `01 9A 00 00 6B` | 00=回零模式 |
| 读驱动参数 | `01 42 6C 6B` | 37 字节按 §12.3 |
| 修改驱动参数 | `01 48 D1 01 <37B参数> 6B` | §12.2 |
| 修改 ID | `01 AE 4B 01 <ID> 6B` | §7.4.5 |

> CAN 帧：数据首字节=功能码；>8 字节命令拆包，帧 ID=(Addr<<8)+包序号。校验：默认最后字节固定 `0x6B`。
> 下表中地址字节 `01` 为示例，实际按关节寻址发送：**J1→02, J2→03, J3→04, J4→05, J5→06, J6→07**（帧 ID 对应 `0x0200..0x0700`）。

## 附录 B：STM32 固件适配参考（get_state/set_joints/remote_event → ZDT）

已适配固件按此映射（供核对）：

| PC 命令 | 固件对 ZDT 的操作 |
|---------|------------------|
| `get_state` | 逐轴读 `0x36`(位置) + `0x35`(转速) + `0x27`(相电流)，换算成 ° / °/s / mA |
| `set_joints` | 逐轴发 `0xFB` 直通限速位置（绝对=01），目标角 clamp 到 §5.1 范围 |
| `remote_event` | 位置环：速度→位置积分→IK→`0xFB` 绝对位置；J5/J6 通道：`0xF6` 速度模式或位置增量 |
| `set_torque` | 发 `0xF3 AB 01/00` 使能/不使能 |
| `e_stop` | 广播 `00 FE 98 00 6B` |
| 回零 | `0x93 88` 设零点 + `0x9A` 触发（或依赖 `O_POT_En` 上电自动） |

**换算注意**：ZDT 位置×10、误差×100、速度×10，放大倍数不一致；`S_PosTDP` 使能后位置×100。**全部在固件统一封装成 ° 后对外**，PC 侧只见角度。
