# zdt_interactive.py 使用教程

> ZDT 电机交互式调试器 —— 直接走 SocketCAN 的**底层调试 / 协议学习 / 标定**工具。
> 支持机械臂 6 个关节电机的操作与标定。

---

## 0. 定位：是什么 / 不是什么

**是什么**：直接读电机寄存器、发原始帧、做脉冲/刻度标定、测生产驱动路径（`ZdtController`）。
贴协议、可学习、能标定。

**不是什么**：没有 `zdt_panel.py` 那套安全状态机（软限位 clamp、看门狗、重力关节确认）。
所有运动命令**直接发出**，安全全靠物理急停 + `estop` 命令 + 自己注意。

> ⚠ **它是调试工具，不是安全面板。** 安全步进请用 [README_zdt_panel.md](README_zdt_panel.md)；底层操作与标定用本工具。

| 能力 | zdt_interactive.py | zdt_panel.py |
|------|--------------------|--------------|
| 安全门禁 | ❌ 无 | ✅ SafetyMachine |
| 单关节失能 | ✅ `dis` | ❌ 无（`D` 是全禁用）|
| 原始帧 / 标定 | ✅ | ❌ |

## 2. 命令全集

### 2.1 六关节操作（批量 / 链路确认）

| 命令 | 作用 |
|------|------|
| `j1` ~ `j6` | 切换当前关节（pc: J1=0x02…J6=0x07；firmware: 0x01…0x06）|
| `scan` | 探测 6 个地址，显示 在线/离线 + 位置 + 标志 |
| `all status` | 读全部关节 pos+cur+flag 一张表 |
| `all en` | 批量使能 6 台 |
| `all dis` | 批量失能 6 台 —— **需输 `all dis CONFIRM`**（重力关节警告）|
| `all stop` | 广播停止（= estop）|

### 2.2 读命令（期待回帧）

| 命令 | 作用 |
|------|------|
| `pos` | 读当前位置（电机轴度，**参考值**）|
| `cur` | 读相电流 mA |
| `flag` | 读状态位：`0x01`使能 `0x02`到位 `0x04`堵转 `0x08`堵转保护 |
| `status` | 一次读 pos+cur+flag |
| `poll [N]` | 连续读位置 N 次（默认无限，Ctrl+C 停）——**手掰臂时实时看读数变化** |

### 2.3 写命令（无回帧）

| 命令 | 作用 |
|------|------|
| `en` | 使能（保持力矩）|
| `dis` | 失能（断力矩——**J2/J3 会掉，手扶住**）|
| `stop` | 停止当前电机 |
| `estop` | 广播急停（0xFE，断命令保力矩，所有电机）|

### 2.4 运动命令（0xFD 固件兼容，已真机验证）

| 命令 | 作用 |
|------|------|
| `fdrel <deg> [spd] [acc]` | 输出角度相对运动。默认 30rpm / acc 20。脉冲 = `deg × CURRENT_RATIO × 3200/360` |
| `fdp <n> [dir] [spd] [acc]` | 原始脉冲数运动。`dir` 0=CW / 1=CCW。**标定用** |

### 2.5 标定与换算

| 命令 | 作用 |
|------|------|
| `ratio [n]` | 查看/设置 CURRENT_RATIO（默认 51.0）——决定 fdrel 脉冲数 |
| `setmed <P> <M>` | 精确标定：发过 P 脉冲、实测输出转 M 度 → `ratio = P×360/(M×3200)` |
| `fixup <cmd> <meas>` | 迭代修正：发 fdrel cmd、实测转 meas → `new = ratio × cmd/meas` |
| `cal <角°> <pos>` | **0x36 刻度标定**：收集(实际角度, pos读数)对，最小二乘拟合 `pos = k×角 + b`（pos 带符号）|
| `anchor` | **上电锚定真实角度**：读 0x36 带符号位置 + `CALIB_OFFSETS`/`CALIB` 换算 → 输出真实角度（限位基准）|
| `clrpos [CONFIRM]` | **清零当前位置**（0x0A 6D）：让 0x36 立刻读出 0（A 任务标定主命令）|
| `setzero [CONFIRM]` | **设单圈回零零点**（0x93 88 01，存储，不可逆）：当前位置设为回零目标（0x36 读数不变）|

### 2.6 生产驱动测试（直连 ZdtController）

| 命令 | 作用 |
|------|------|
| `prod status` | 读输出轴角度（软件跟踪）/电流 |
| `prod mv <deg>` | 运动到目标输出角度 |
| `prod rel <deg>` | 输出轴相对运动 |
| `prod reset` | 回初始位姿（soft_reset → 开机姿态全 0） |
| `prod ready` | **6 轴同步慢速运动至按摩准备姿态**（见下） |

#### `prod ready` 使用方法

**作用**：整机（6 轴）同步、慢速运动到按摩准备姿态 `READY_POSE_DEG`。
与 `prod reset`（回开机姿态全 0）的区别：ready 是**按摩作业的准备位**，各关节
位于 [0, 60, 50, 0, 120, 0]（经 CALIB(k,b) 换算的真实输出角度，全部在限位内）。

**流程**（`controller.ready()`，与 `set_joints_safe` 同基准）：
1. 读 6 轴 0x36 真实位置 → 经 CALIB(k,b) 换真实角（anchor 基准）
2. 各轴目标 clamp 到限位 → 相对真实位置最短路径 → 脉冲
3. 每轴发 0xFD（**snF=1 多机同步标志**，速度 `READY_SPEED_RPM=10`）只设不转
4. 发广播 `00 FF 66 6B` → 6 轴**同时启动**
5. 已到位轴（delta=0）不发；全部到位则不广播（提示"已在按摩准备姿态"）

**特点**：
- **慢速仅本条生效**：`READY_SPEED_RPM=10`（电机轴 RPM），不改全局 `speed_rpm`（60）
- **同步启动**：多机同步广播，避免各轴先后到位造成姿态畸变
- **安全**：限位 clamp + 0x36 真实位置基准，失步/外力搬动后仍准确

**用法示例**：
```bash
en                 # 先使能
prod ready         # 6 轴同步慢速 → 准备姿态 [0,60,50,0,120,0]
all status         # 复核: anchor 列应 ≈ 目标值 (±1°)
```

> ⚠ ready 会运动并使能电机。操作前确认安全区无人、急停可及；如仅需回开机姿态
> 用 `prod reset`（全 0），如需绝对基准先 `anchor`。

## 3. 关键概念：0x36 是带符号真实位置

> ⚠ **本节是标定的理论基础，请先读清楚再用 `cal`/`anchor`/`clrpos`/`setzero`。**

### 3.1 0x36 的真实语义

ZDT 说明书 §7.4.4 + 固件 `robot.c:1045` 实测确认：

```
0x36 回帧: [36, 符号字节, 位置×10 (3字节大端), 6B]
符号字节: 0x00 = 正,  0x01 = 负
```

**0x36 返回的是带符号的实时位置（电机轴角度，×10 倍率），不是"V型绝对值"。**
旧版交接文档说"0x36 只给离 0 的距离、不给方向"是**错误认知**，已修正。

### 3.2 三个容易混淆的命令

| 命令 | 功能码 | 改 0x36 当前读数? | 改回零目标? | 用途 |
|------|--------|-------------------|-------------|------|
| `clrpos` | 0x0A 6D | ✅ 立刻读出 0 | ❌ | **标定主命令**：清零当前位置，此后 0x36 读相对偏移 |
| `setzero` | 0x93 88 01 | ❌ 不变 | ✅ 设为当前位置 | 设回零目标点，触发 `home` 会回到这里 |
| `home` | 0x9A mode 00 | — | — | 触发回零运动到 `setzero` 设的目标（本工具已暴露） |

**A 任务标定用 `clrpos`（0x0A 6D）**，因为我们要的是"让 0x36 此后读相对偏移"，不是"设回零目标"。
完整职责边界与"断电记忆回零闭环"见 **§3.4**。

### 3.3 两种标定路线（互斥）

| 路线 | 标定表 | 公式 | 适用 |
|------|--------|------|------|
| **简单偏置** | `CALIB_OFFSETS` | `真实 = (0x36/减速比) - offset` | 减速比已知、只需零点偏置 |
| **精确 (k,b)** | `CALIB` | `真实 = (0x36 - b) / k` | 减速比也要校准 |

未标定时（两表对应槽位都是 `None`）退化为纯减速比换算（无偏置修正），仅作参考。

### 3.4 三层换算关系 + setzero/home/clrpos 职责边界 + 断电记忆

#### 3.4.1 底层量化：位置到底是怎么从编码器到角度的

电机位置在系统里经历 **三层不同的"数"**，混用是大多数困惑的来源：

| 层次 | 量化的"数" | 单位 / 基准 | 断电是否保持 |
|------|-----------|------------|:---:|
| **① 编码器刻度**（最底层） | `0 ~ 65535` | 电机轴 **1 圈 = 65536**（16384 线磁编码器 ×4 正交） | ❌ 上电重算 |
| **② 0x36 读数**（驱动器返回） | ×10 放大整数 | `0.1° / 电机轴`（说明书 §7.4.4：`0x00001C19=7193=719.3°`） | ❌ RAM 清零 |
| **③ 输出轴角度**（PC 侧） | 角度 float | `(0x36 − b)/k` 或 `0x36/减速比 − offset`，再加初始位 | 由 PC 计算 |

**换算链路**（自上而下 / 自下而上）：
```
电机轴 1圈 = 65536 编码器刻度 = 3600 个 0x36 计数 (0.1°×360)
    ↓ 0x36 计数 × 0.1°           → 电机轴角度
    ↓ ÷ 减速比 (g_ratio)          → 输出轴角度 (未经偏置修正)
    ↓ − offset 或 (CALIB k,b)     → 输出轴真实角度
```

> ⚠ **要点**：固件 `robot.c:1056` 用 `×360/65536` 假设"一圈=65536 读数"，与说明书"0.1° 一圈=3600"**不一致**——固件换算针对旧代/特定模式，PC 侧 `read_pos` 按说明书 `÷POS_SCALE(10)` 即 `×0.1°` 为准。

#### 3.4.2 setzero / home / clrpos 职责边界（到底改哪个"数"）

| 命令 | 改变的层次 | 存的基准 | 断电记忆 |
|------|-----------|---------|:---:|
| `clrpos` (0x0A 6D) | ② 0x36 计数清零 | 把"此刻"记为新 0 | ❌（RAM） |
| `setzero` (0x93 88 01) | ① 编码器刻度存为**零点偏移** | 把"此刻机械位置"存为回零目标 | ✅（Flash） |
| `home` (0x9A) | ① 驱动到"编码器刻度==零点偏移" | 回 `setzero` 存的零点 | — |

**一句话记忆**：
- `clrpos` = 改 **0x36 的读数**（让 pos 立即变 0，**不**记忆）
- `setzero` = 改 **编码器的零点偏移**（记一个绝对机械位，**记忆**，是回零目标）
- `home` = 让电机 **回到** setzero 记的那个位

#### 3.4.3 断电记忆：驱动器的回零闭环（V2 说明书支持）

0x93/0x9A 之所以"断电能找回零点"，是因为 **零点偏移存在驱动器 Flash**（一个编码器绝对刻度 0~65535），上电后磁编码器重新读绝对刻度，能算出离零点差多少并转回去。

```
第一次: 摆到已知初始位 → setzero CONFIRM        (存零点到 Flash)
        → origin set CONFIRM 0 0 30 1           (配参数 + 使能上电自动回零)
之后每次上电: 驱动器自动回零到零点 → pos=0 = 零点 → anchor 基准有效
或手动: home CONFIRM 触发回零
```

**补充命令**（同时已加进工具）：
- `origin`：读回零参数（0x22）；`origin status`：读回零状态（0x3B）
- `origin set`：配回零参数并存储（0x4C 0xAE）；`home stop`：中断回零（0x9C 48）

> ⚠ **真机风险**：这些命令来自 **V2 说明书（Rev1.0）**。你的驱动器固件版本可能不支持（此前 0xFB 直通限速就不识别）。先用 `origin`（读参数、无副作用）确认固件应答，再碰 `setzero`/`home`/`origin set`。

## 4. 标定命令详解

### 4.1 `cal`：拟合 0x36 刻度 (k, b)

**用法**：
```
cal <角°> <pos>   # 添加标定点并实时拟合 (如: cal 90 1303)
cal               # 显示当前点 + 拟合结果
cal del           # 删除最后一个点 (回退误输入)
cal clear         # 清空所有点
```

**输出示例**（J5: k≈27 减速比, 电机轴度 pos → 输出角度）：
```
  拟合: pos = 27.0117 × 角度 − 0.83
  换算: 输出角度 ≈ (pos + 0.83) / 27.0117
  质量: R²=0.9999  逐点最大角度偏差 0.12°
  记录: 把 (k, b) 填入 config.py 的 CALIB 对应关节槽, 即可用 anchor 锚定
```

> ⚠ **k 值单位（2026-08-21 decode_pos4 修正后）**：0x36 读数已是**电机轴度**，拟合 k≈**减速比**（如 J5 k=27.0117≈27、J6 k=51.009≈51），不再是旧解码下的 3.6xxx。旧示例 `k=3.6194` 作废。
> ⚠ **单圈范围**：0x36 位置 0~65535 = 电机轴一圈，超过一圈会回绕。扫点应保持在电机轴 ±360° 内（高减速比关节只对应输出轴几度），或每点先 `clrpos` 再相对读数。

**要点**：
- pos **带符号**，拟合 `pos = k×角 + b`（线性，不取绝对值，不用分侧扫）
- **≥2 个点**且**点间角度差拉开**才拟合；不满足会明确提示
- `R²` 看贴合度，`逐点最大角度偏差` 反查测量准不准
- **每台电机独有**（减速比、装配零点都不同），勿跨关节套用
- 标定点按电机地址分开存放：切 `jN` 自动切到该关节自己的点

### 4.2 `anchor`：上电锚定真实角度

**前提**：该关节 `CALIB_OFFSETS` 或 `CALIB` 已标定（`config.py` 对应槽位填入值）；否则可用临时参数验证。

**用法**：
```
anchor              # 按当前关节标定表锚定
anchor <k> <b>      # 临时用给定 k,b 锚定 (未标定时验证用)
anchor <offset>     # 临时用给定 offset 锚定 (CALIB_OFFSETS 路线)
```

**行为**：读 0x36 带符号位置 → 用 `CALIB_OFFSETS`/`CALIB`/临时参数换算 → 输出真实角度：
```
锚定 J6(0x07): pos=+510.1  CALIB(k=51.009, b=0.01)
→  真实输出角度 ≈ +10.0°
此值即面板 tracked_deg 的初始化基准 (上电/外力搬动后重新 anchor)
```

> ⚠ **k 值单位**：2026-08-21 `decode_pos4` 修正后，0x36 读数已是电机轴度，`cal` 拟合的 k≈**减速比**（如 J6 k=51.009），不再是旧解码下的 3.6xxx。旧的 `k=3.6194` 示例已作废。

**意义**：上电时软件不知道真实位置（`tracked_deg` 默认按假设位姿初始化）。`anchor` 让你**一次性告诉软件真实位置**，之后命令积分持续追踪——这是「限位基于真实位置」的第一步。

> 旧版 `anchor` 要用户指定符号（`+`/`-`）是基于"0x36 是 V 型绝对值"的错误认知。0x36 本身带符号，已修正。

### 4.3 `clrpos`：清零当前位置（A 任务标定主命令）

**用法**：
```
clrpos          # 提示后需输 clrpos CONFIRM 才执行
clrpos CONFIRM  # 直接执行
```

**行为**：发 `0x0A 6D` → 0x36 立刻读出 0 → 验证 pos≈0 → 提示下一步用 `anchor` 锚定并存 `CALIB_OFFSETS`。

**与 `setzero` 的区别**（重要）：
- `clrpos`（0x0A 6D）：**改 0x36 当前读数**，让此后 0x36 读相对偏移。不影响回零目标。
- `setzero`（0x93 88 01）：**设回零目标**，触发 `home` 会回到这里。但 0x36 当前读数不变。

A 任务标定方案 b（人工摆姿态 → 清零 → 此后读相对偏移）用 `clrpos`。

### 4.4 `setzero`：设单圈回零零点

**用法**：
```
setzero          # 提示后需输 setzero CONFIRM 才执行
setzero CONFIRM  # 直接执行 (先摆好位置!)
```

**行为**：发 `0x93 88 01`（持久写入驱动器，不可逆）→ 当前位置设为回零目标 → 提示 0x36 读数不变是正常（0x93 设回零目标，不清零当前）→ 触发回零用 `home CONFIRM`（0x9A，**已在工具暴露**）。

> ⚠ `setzero` 是**持久写入驱动器、不可逆**。设零后固件假设的初始位姿不再对齐，之后以 `anchor`/`CALIB` 为权威。
> 若想让 0x36 立刻读出 0，用 `clrpos`（0x0A 6D），不要用 `setzero`。
> `home CONFIRM [mode]` 触发回零运动到 `setzero` 设的目标；`home stop` 中断。
> 完整的断电记忆回零闭环见 **§3.4.3**：`setzero` → `origin set CONFIRM ... 1`（使能上电自动回零）→ 上电自动回零点。

## 5. 典型工作流

### 工作流 A：链路确认（每次上电第一步）

```bash
scan
# J1 0x02: 在线 FW/HW=0x5/0x82 位置=+50.0°(电机轴)  0x03[使能,到位]
# ...
# 全部在线 (6/6) ✓
```

在线不齐就先排查（供电/重复 ID/波特率/Response 设置），别往下走。

### 工作流 B：0x36 刻度标定（`cal`）+ 锚定验证

以 J4 为例（非重力，先练手）：

```bash
j4              # 切到 J4
dis             # 单关节失能 (其余保持使能稳臂)
poll            # 手掰到 0° 停稳, Ctrl+C
cal 0 0         # 基准点 (0° → pos 应≈0)
[手掰到 +30°]  pos      # 记 pos 读数
cal 30 <pos>
[手掰到 +60°]  cal 60 <pos>
[手掰到 +90°]  cal 90 <pos>
cal             # 看拟合, 抄下 (k, b)
```

标定完填入 `config.py` 的 `CALIB` 对应槽位，再锚定验证：

```bash
anchor          # 应输出与手摆位置一致的真实角度
# 锚定 J4(0x05): pos=...  CALIB(k=..., b=...)
# →  真实输出角度 ≈ +30.0°   ← 应与手摆位置一致
```

> `poll` 实时看变化、`pos` 取停稳精确值。J2/J3 全程手扶。
> 0x36 带符号，不用分侧扫，正负角度都能直接标定。

### 工作流 C：A 任务标定（`clrpos` + `anchor`，方案 b）

这是本次 A 任务的**主标定流程**：人工摆到已知姿态 → 清零 → 记录偏置。

```bash
# 1. 人工把机械臂摆到已知姿态 (如固件初始位 [90,90,-90,0,90,0])
# 2. 对每轴执行:
j1
clrpos CONFIRM  # 清零当前位置, 0x36 此后读相对偏移
anchor          # 读 0x36 + 标定换算 → 输出真实角度, 记录 offset
# 3. 把 offset 填入 config.py 的 CALIB_OFFSETS 对应槽位
# 4. 之后用 ctrl.set_joints_safe() 做限位 (基于 0x36 真实位置)
# 5. 定期 ctrl.check_drift() 检查漂移, 超阈值重新 anchor
```

### 工作流 D：减速比标定（驱动器脉冲 ↔ 真实角度）

```bash
en              # 先使能
fdp 32000 0 60  # 发 32000 脉冲 (模型 10 圈), 输出轴绑指针+固定参考
# 数指针转了多少圈 → 得实测 M
setmed 32000 M  # ratio = P×360/(M×3200), 直接精确标定
fdrel 90        # 复核: 指针应精确转 90°
prod mv 90      # 验证生产 set_joints 同步 OK
# 有偏差再 fixup 一次收敛
```

### 工作流 E：底层协议学习 / 排障

```bash
raw 360010F4    # 发原始位置读
mon 5           # 监听总线上所有帧
send 0x03 FD00  # 向指定 ID 发原始帧
```

## 6. 安全提醒（此脚本尤其重要）

1. **无软限位、无看门狗、无门禁**——`fdrel`/`fdp`/`prod` 输进去就发，发前自己核对角度/方向
2. **`dis` 前先想清楚**：J2/J3 失能即失去力矩，会因重力坠落，**先手扶住再 `dis`**
3. `all dis` 有 `CONFIRM` 门槛防手滑，但**真正安全是物理急停**
4. `estop` 断命令但**保力矩**——手臂不会掉；要完全断电矩用 `dis`
5. 运动命令先小角度试（`fdrel 1`）确认方向，再加大

## 7. 常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| 提示符不变（`[0x02]`）| 没切关节 | 输 `j1`~`j6` |
| `pos` 超时 | 地址不对 / 离线 / Response=None | `scan` 确认在线；`addr` 切换 |
| `dis` 后掰不动 | 驱动失能行为差异 | 停！反馈 |
| 手掰时 `pos` 不变 | 0x36 不实时更新 / 还在使能 | 确认 `dis` 生效、用 `poll` 看变化 |
| `fdrel` 方向反了 | 关节正方向定义 | 换负角度试；J1/J5 dir 字节为 1 |
| `cal` 说"角度过于集中" | 点间角度差太小 | 拉开角度再采 |
| `anchor` 提示未标定 | 该关节 `CALIB`/`CALIB_OFFSETS` 都为 None | 先 `cal` 标定填入 config，或 `anchor <k> <b>` / `anchor <offset>` 临时验证 |
| `clrpos` 后 pos 不为 0 | 清零失败 / 位置已动 | 代码容差 ±1° 内判成功；超出则重新摆到基准位再清，或用 `pos` 手动核对 |
| `setzero` 后 pos 不为 0 | **正常**——0x93 设回零目标，不改 0x36 当前读数 | 想让 0x36 读 0 用 `clrpos`；`setzero` 的效果用 `home` 触发回零验证 |
| OLED 不随手掰变化 | 屏幕显示命令侧位置，失能不走命令 | **属正常**——校准认 `pos`/CAN 读回值 |
