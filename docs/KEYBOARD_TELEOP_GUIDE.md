## 1. 架构与控制原理

键盘遥操工具提供了一种在没有相机或游戏手柄时，对机械臂末端执行器进行**毫米级笛卡尔空间精密微调与示教**的能力。

```text
┌────────────────────────────────────────────────────────┐
│  按键监听 (W/A/S/D/Q/E 等)                             │
└──────────────────────────┬─────────────────────────────┘
                           │ 笛卡尔目标线速度/角速度 (v, w)
┌──────────────────────────▼─────────────────────────────┐
│  CartesianController (阻尼最小二乘 DLS 逆解)            │
│  • 雅可比矩阵 J(q) 计算                                  │
│  • 奇异点阻尼重整化 dq = (J^T J + λ^2 I)^(-1) J^T · twist │
│  • 单步最大跳变限幅 (dq <= 30°/step)                     │
└──────────────────────────┬─────────────────────────────┘
                           │ 6 轴目标相对转角增量 (dq_1 ~ dq_6)
┌──────────────────────────▼─────────────────────────────┐
│  ZdtController (SocketCAN can0 @ 500kbps)              │
│  • 50ms 周期下发 0xFD 相对位置脉冲                      │
│  • 0x1F 状态与电机编码器多圈绝对角度回读               │
└────────────────────────────────────────────────────────┘
```

## 2. 运动学建模与 DLS 逆解算法

机械臂采用 6 轴修正 DH（MDH）参数建模：

| 关节 | 连杆偏距 $a_{i-1}$ (mm) | 扭转角 $\alpha_{i-1}$ (rad) | 连杆偏置 $d_i$ (mm) | 关节角零位 $\theta_i$ 偏置 | 减速比 |
|---|---|---|---|---|---|
| **J1** | 0.0 | 0.0 | 0.0 | 0.0 | **51 : 1** |
| **J2** | 0.0 | $+\pi/2$ | 0.0 | $+\pi/2$ | **51 : 1** |
| **J3** | 200.0 | $\pi$ | 0.0 | $-\pi/2$ | **51 : 1** |
| **J4** | 47.63 | $-\pi/2$ | $-184.5$ | 0.0 | **51 : 1** |
| **J5** | 0.0 | $+\pi/2$ | 0.0 | $+\pi/2$ | **27 : 1** |
| **J6** | 0.0 | $+\pi/2$ | 0.0 | 0.0 | **51 : 1** |

### 逆解特点：
- **速度级控制**：直接在微分运动学层面求解 $\Delta \boldsymbol{q} = \boldsymbol{J}^{\dagger} \boldsymbol{v} \Delta t$；
- **奇异点鲁棒性**：在机械臂完全伸直或肩/腕奇异区，DLS 阻尼因子 $\lambda$ 自动生效，避免关节角速度发散。

## 3. 键盘按键映射与操作说明

### 3.1 空间平移控制（基座坐标系 Base Frame）
- **`W` / `S`**：末端沿 **+X / -X** 平移（前进 / 后退）；
- **`A` / `D`**：末端沿 **+Y / -Y** 平移（向左 / 向右）；
- **`Q` / `E`**：末端沿 **+Z / -Z** 平移（垂直上升 / 下降）。

### 3.2 姿态微调与旋转控制
- **`I` / `K`**：末端绕 X 轴旋转（Roll 翻滚）；
- **`J` / `L`**：末端绕 Y 轴旋转（Pitch 俯仰）；
- **`U` / `O`**：末端绕 Z 轴旋转（Yaw 偏航）。

### 3.3 档位与功能按键
- **`1` / `2` / `3`**：切换速度档位（1档: 10 mm/s, 2档: 30 mm/s, 3档: 60 mm/s）；
- **`R`**：平缓运动至按摩预设准备姿态 (READY)；
- **`H`**：平缓运动回垂直初始复位姿态 (HOME)；
- **`P`**：终端实时打印当前 6 轴角度与末端笛卡尔位姿（调谐示教用）；
- **`SPACE`**：急停并切断电机驱动力矩；
- **`ESC` / `Q`**：退出键盘遥控。

## 4. 启动步骤 (统一 CLI 推荐)

```bash
# 激活环境
conda activate arm_robot

# 方式 A：控制真实机械臂
sudo ip link set can0 type can bitrate 500000 && sudo ip link set can0 up
arm-robot keyboard --iface can0

# (终端 1 先启动仿真: arm-robot sim --viewer)

```

## 5. 6 轴真机方向验收测试清单

首次在新机械臂上运行时，请按以下验收清单验证运动方向：

1. **Step 1（Z 轴上升）**：轻点 `Q` 键，确认末端垂直向上抬升约 10mm；
2. **Step 2（X 轴前进）**：轻点 `W` 键，确认末端向前延伸约 10mm；
3. **Step 3（Y 轴横移）**：轻点 `A` 键，确认末端向左横移约 10mm；
4. **Step 4（准备姿态复位）**：按 `R` 键，确认机械臂 6 轴平稳运行至前倾推拿准备位，无干涉与撞击。

## 6. 安全机制与故障排除

1. **工作空间硬限幅**：末端工作空间限制在半径 $R \in [150, 480]\text{ mm}$，底座高度 $Z \ge -50\text{ mm}$，防止撞击桌面；
2. **通信超时保护**：键盘释放后立即下发 0 速度，50ms 无指令自动维持位置锁定；
3. **单步角突变抑制**：单步最大允许角度跳变 $\Delta q \le 30^\circ$，防止逆解奇异造成飞车。
