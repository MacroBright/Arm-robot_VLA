### 1.2 编码标准与代码坏味道轴 (Standards Axis)

- **无动态内存分配（Real-time Safe）**：遥操循环内无递归与大规模对象重建，所有图像与数据结构复用预分配缓冲区；
- **异常捕获与窗口容错**：OpenCV Qt 窗口探测均受 `try...except` 保护，杜绝 Wayland/Qt 崩溃；
- **命名与类型提示**：全面采用 Python 3.10+ 类型注解（`dict | None`, `Optional`, `tuple`），符合 PEP 8 规范；
- **单一职责原则**：视觉提取（`wrist_tracker`）与总线适配（`arm_adapter`）严格分层，无跨层污染。

## 二、机器人硬件安全核心审查 (Robotics Hardware Safety Gate)

### 2.1 机械与电气安全边界 (Safety Envelope)

```
                       【硬件安全硬限幅层 (Safety Envelopes)】
                                       │
      ┌────────────────────────────────┼────────────────────────────────┐
      ▼                                ▼                                ▼
【末端平移线速度上限】            【末端旋转角速度上限】             【单控制周期最大关节角】
  |v_lin| ≤ 80.0 mm/s              |w_ang| ≤ 0.8 rad/s              |Δq_max| ≤ 2.0 deg
  (电机转速 ≤ 113 RPM)             (输出角速度 ≤ 45.8°/s)           (高频跟踪步长保护)
```

1. **关节机械与软件限位**：
   - J1（基座）：$[-1.0^\circ, 360.0^\circ]$
   - J2（肩抬重力关节）：$[-1.0^\circ, 150.0^\circ]$（带物理重力下坠保护）
   - J3（肘部重力关节）：$[-1.0^\circ, 120.0^\circ]$
   - J4（腕部翻转）：$[-90.0^\circ, 90.0^\circ]$
   - J5（腕部俯仰）：$[-1.0^\circ, 180.0^\circ]$
   - J6（末端自旋）：$[-1.0^\circ, 360.0^\circ]$
2. **通信超时保护（Watchdog Timer）**：
   - PC 笛卡尔控制器单周期超过 $250\text{ ms}$ 无有效命令，直接触发 `stale_command` 刹停；
   - 视觉信号丢失超过 $400\text{ ms}$ 进入 `STOP`，丢失 $>1.0\text{s}$ 自动触发 `ESTOP` 并切断使能。

## 三、真机断电 Dry-Run 验证清单 (Power-Off Dry-Run Checklist)

在接通电机 24V/48V 驱动母线高压动力电源之前，**必须在电机断电（仅 CAN 通信卡与主控板供电）状态下执行断电演练**：

```
[步骤 1: 物理准备] ──► [步骤 2: 通信探测] ──► [步骤 3: 信号闭环] ──► [步骤 4: 遥操演练]
```

### 3.1 预检核对表

- [ ] **1. 电源状态检查**：确认电机主驱动电源（高压动力电源）处于**物理断开（OFF）**状态，仅 USB-CAN 模块与 PC 连接；
- [ ] **2. 机械自由度与卡死检查**：手动轻推机械臂各关节，确认各轴无机械干涉、无碰撞阻碍；
- [ ] **3. CAN 接口通信就绪**：
  ```bash
  sudo ip link set can0 up type can bitrate 500000
  ip link show can0  # 状态应为 UP
  ```
- [ ] **4. 驱动器节点探测（Ping / Scan）**：
  运行驱动器枚举，确认 6 个关节驱动器（CAN ID `0x01` ~ `0x06` 或 `0x02` ~ `0x07`）均正常响应通信报文：
  ```bash
  candump can0 &
  # 发送 0x36 读取帧，确认无总线错误（Error Passive/Bus-off）
  ```
- [ ] **5. 启动视觉遥操断电演练模式**：
  ```bash
  python scripts/teleop/real_arm_teleop.py --iface can0 -y
  ```
- [ ] **6. 遥操动作与报文抓取闭环演练**：
  - 观察终端与 OpenCV 窗口：画面实时捕获手势，`dPitch` / `dRoll` 稳定响应；
  - 按 `SPACE` 键：确认系统状态由 `[CLUTCH PAUSED]` 变为绿色 `[TELEOP ACTIVE]`；
  - 移动手掌：通过 `candump can0` 观察 CAN 总线上有规律发送 `0xFD` / `0xF6` 速度控制报文，且速度字段严格在计算限幅内；
  - 移出手掌：确认 0.4s 后 CAN 总线速度报文自动归零（`0x00`），1.0s 后触发 `ESTOP`；
  - 按 `Y` 键或 `Q` 键：确认触发急停报文，总线安全退出。

## 四、5% 低速渐进式实机测试方案 (5% Low-Speed Test Plan)

完成断电演练后，进入**实机上电分级测试**。

> [!CAUTION]
> **黄金安全准则**：
> 1. 测试场地周围 1.5 米内禁止站人；
> 2. 操作员左手必须放在键盘 **`SPACE`（暂停） / `Y`（急停） / 物理急停开关** 上，右手进行手势遥操；
> 3. 首次测试必须从 **5% 低速极限** 开始验证。

### 4.1 分级测试阶梯 (Test Ladder)

| 阶段 (Phase) | 测试内容 | 速度上限配置 | 预期目标 | 准出条件 (Exit Criteria) |
|:---|:---|:---:|:---|:---|
| **Phase 1: 单轴微动响应测试** | 启动低速驱动，分别测试单个关节的正反向响应 | 5% 速度<br>($v \le 4\text{ mm/s}$, $\omega \le 0.04\text{ rad/s}$) | 验证电机转向与 DBC 协议符号是否 100% 一致 | 6 个关节各点动 5°，方向正确，无振动 |
| **Phase 2: 5% 超低速遥操测试** | 启用 5% 限速模式进行手势空间遥操 | 5% 速度<br>($v \le 4\text{ mm/s}$, $\omega \le 0.04\text{ rad/s}$) | 验证手向前推 $\to$ 臂向前动；手下压 $\to$ 臂向下压 | 连续遥操 60 秒无卡顿、无冲顶、回中即停 |
| **Phase 3: 20% 中速推拿位姿测试** | 恢复到推拿标准速度（20%~30%） | 25% 速度<br>($v \le 20\text{ mm/s}$, $\omega \le 0.2\text{ rad/s}$) | 测试推拿滚揉、前后走罐轨迹的手势控制平滑度 | 姿态变换流畅，电机噪音均匀，力控无冲击 |
| **Phase 4: 全功能安全演练测试** | 模拟视觉遮挡、突然抽手、紧急拍停 | 全速限制<br>($v \le 80\text{ mm/s}$, $\omega \le 0.8\text{ rad/s}$) | 验证所有软硬件看门狗与急停链路 | 遮挡时自动平稳停机，按 SPACE 恢复正常 |

### 4.2 5% 低速遥操启动命令

执行以下命令即可启动 **5% 超低速安全守护模式**（内置速度硬钳制）：

```bash
# 5% 超低速安全实机测试 (线速度 ≤ 4mm/s, 角速度 ≤ 0.04rad/s)
python scripts/teleop/real_arm_teleop.py --iface can0 -y --low-speed 0.05
```
