## 一、项目背景

基于 **VLA（Vision-Language-Action）** 的机械臂 + 灵巧手按摩系统。
将 zero-robotic-arm（STM32F407 + Emm_V5 CAN 步进闭环驱动器）集成到 LeRobot 生态。

### 技术栈
| 层 | 技术 |
|----|------|
| VLA 模型 | SmolVLA-450M (PyTorch) |
| 框架 | LeRobot (Hugging Face) |
| 上位机 | Python 3.10+, pyserial, OpenCV |
| 下位机 | STM32F407VET6, FreeRTOS, CAN |
| 电机 | Emm_V5 CAN 步进闭环驱动器 ×6（6-DOF） |
| 灵巧手 | AmazingHand（设计中） |

### 关键架构决策（ADR）
- **ADR-001**：STM32 是安全网关，PC 不能绕过（禁止直接 LeRobot `FeetechMotorsBus`）。
- **ADR-002**：PC↔STM32 使用行文本协议（ASCII, `\n`），波特率 115200。
- **ADR-003**：自定义 `MassageRobot` 子类管理通信（BYOH Approach A）。
- **ADR-004**：Emm_V5 CAN 步进电机，非 STS3215 RS485 舵机。
- **ADR-005**：**PC 直连 CAN**（非中继/网关），`transport="can"`，不经过 STM32 中继。
- **ADR-006**（2026-08-20）：**0x36 是带符号真实位置**（不是"V 型绝对值无方向"）。标定用 `0x0A 6D`（清零当前位置）路线，不走 `0x93+0x9A`（单圈回零）。详见 §四。
- **ADR-007**（2026-08-21）：**驱动器断电台记忆回零**为"上电自动定位"候选方案。0x93/0x9A 零点偏移存 Flash，上电自动回零到零点（pos=0=零点）。新增 `home`/`origin` 命令；真机验证固件支持性中。备选方案：PC 上电自动 `anchor`。
- **ADR-008**（2026-08-21，真机定型）：**本机驱动器固件不支持 CAN 回零**（0x9A 无响应、0x4C 0xAE 不持久化）。**选定 PC 方案A**：上电跑 `zdt_anchor.py` 读 0x36 真实角度建立基准。驱动器断电记忆回零仅留作板载屏/固件升级后的可选项。
- **ADR-009（重大，2026-08-21）**：**本机电机是 Emm42 V5.0**（正确说明书：`docs/Emm_V5.0_步进闭环驱动说明书.md`；之前参照的 `ZDT_X系列_V2` 说明书错误，已移出知识库）。0x36 位置字段实为 **4 字节 ×360/65536**，PC 端 `decode_pos3`（3字节×10）**错误** → 丢最低字节 + 单位错。**待专项修正（§六 任务书）**。

## 四、关键技术澄清（2026-08-20 新增）

> ⚠ **2026-08-21 更新**：下文"0x36 语义"已修订 —— 0x36 位置字段是 **4 字节 ×360/65536**，不是"3 字节 ×10"。PC 端解码已于 2026-08-21 修正为 `decode_pos4`（见 §六 专项完成状态）。

### 0x36 命令的真实语义（已实证修订）

**旧认知（错误）**：
1. "V 型绝对值，只给离 0 的距离，不给方向" —— 错，已修正为带符号。
2. "位置 3 字节 ×10" —— **错，本次实证发现是 4 字节 ×360/65536**。

**实证结论（真机 `raw 36` + 固件源码 + Emm42 V5.0 说明书三方一致）**：
- 0x36 返回**带符号实时位置**，格式 `[0x36, 符号(0x00=正/0x01=负), 位置4B, 0x6B]`。
- **位置字段 4 字节**，值范围 0~65535 = 一圈，**换算 `角度 = value × 360 / 65536`**（非 ÷10）。
- 真机证据：J5 返回 `36 00 00 00 00 09 6b` → 位置 `0x00000009=9` → `9×360/65536 = 0.0494°`（电机轴）。
- 固件 `robot.c:1041-1056`：读 `rxData[2..5]` 4 字节，`×360/65536`。✓
- Emm42 V5.0 说明书 §0x36：4 字节，`×360/65536`。✓
- **PC 端 `decode_pos3`（data[2:4] 3字节÷10）与上述冲突 → 丢最低字节(≤1.4°量化) + 单位错**。

**符号位**：固件 `robot.c:1045` 用 `rxData[1] == 0x01` 判负；PC `data[1] == 0x01` 已修正。✓

**影响（2026-08-21 已修正代码，CALIB 待真机重标定）**：

- ✅ `read_pos`/`decode_pos4` 已改为 4 字节 ÷65536（§六专项任务已完成）。
- ⚠ CALIB(k,b) 旧值建立在错误解码上，**需全量重标定**（下一会话真机执行）。
- 修正前锚定/限位"自洽但不精确"（丢 1.4° 量化台阶）→ 现已消除。

### 三个易混命令对比

| 命令 | 功能码 | 语义 | 0x36 读数变化 | 使用场景 |
|------|--------|------|---------------|----------|
| `clrpos` | `0x0A 6D` | 清零当前位置 | **立刻变 0** | A 任务标定主命令 |
| `setzero` | `0x93 88 01` | 设单圈回零零点 | **不变** | 设回零目标点（存 Flash） |
| `home` | `0x9A mode 00` | 触发回零运动 | 电机转动 | 配合 setzero 用（交互工具已暴露） |

### setzero/home/clrpos 职责边界（改哪个"数"）

| 命令 | 改变的层次 | 断电记忆 | 记忆性 |
|------|-----------|:---:|------|
| `clrpos` (0x0A 6D) | ② 0x36 计数清零 | ❌ RAM | 只改 pos 读数 |
| `setzero` (0x93 88 01) | ① 编码器刻度存零点偏移 | ✅ Flash | 记一个绝对机械位 |
| `home` (0x9A) | ① 驱动到"刻度==零点偏移" | — | 回 setzero 存的位 |

> **一句话记忆**：`clrpos` 改 pos 读数（不记忆）；`setzero` 存零点偏移（记忆，是回零目标）；`home` 回到那个目标。

### 三层换算关系（编码器刻度 → 0x36 → 输出轴）

| 层次 | 量化的"数" | 单位 / 基准 | 断电 |
|------|-----------|------------|:---:|
| ① 编码器刻度 | `0~65535` | 电机轴 1 圈=65536（16384 线×4） | ❌ |
| ② 0x36 读数 | ×10 放大 | `0.1° / 电机轴`（说明书 §7.4.4） | ❌ RAM |
| ③ 输出轴角度 | float | `(0x36−b)/k` 或 `0x36/减速比 − offset` | PC 算 |

```
电机轴1圈 = 65536 刻度 = 3600 个 0x36 计数 (0.1°×360)
   ↓ ×0.1° → 电机轴角度 → ÷减速比 → 输出轴角度 → 偏置修正 → 真实角度
```

> ⚠ 固件 `robot.c:1056` 用 `×360/65536`（一圈=65536 读数），与说明书 `0.1°`（一圈=3600）**不一致**——PC 侧 `read_pos` 以说明书 `÷POS_SCALE(10)` 为准。

### 断电记忆回零闭环（V2 说明书支持，2026-08-21 已加入工具）

0x93/0x9A 的"断电能找回零点"原理：**零点偏移存驱动器 Flash**（编码器绝对刻度 0~65535），上电后磁编码器重读绝对刻度，算出距零点差多少并转回去。

```
第一次: 摆到已知初始位 → setzero CONFIRM        (存零点到 Flash)
        → origin set CONFIRM 0 0 30 1           (配参数 + 使能上电自动回零)
之后每次上电: 驱动器自动回零到零点 → pos=0 = 零点 → anchor 基准有效
或手动: home CONFIRM 触发回零
```

**已新增交互命令**：`home [mode]` / `home stop` / `origin` / `origin status` / `origin set`（见 §五 仓库结构 & README §3.4）。

> ⚠ **真机风险**：回零命令（0x9A/0x4C/0x22/0x3B）来自 V2 说明书，你的固件版本可能不支持（此前 0xFB 直通限速就不识别）。先用 `origin`（读参数、无副作用）确认固件应答，再碰 `setzero`/`home`/`origin set`。

### 标定方法选择

- **CALIB(k,b)**：`输出角度 = (pos - b) / k`，处理电机轴→输出轴的减速比 + 零点偏置。适合需要精度的场景。
- **CALIB_OFFSETS**：`真实角度 = (0x36读数 / 减速比) - offset`，简单偏置。适合快速标定。
- 两者互斥，同一关节只用其一。
